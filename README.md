# Questions — Q&A Memory

A persistent log of questions and their answers.

## How it works

Every question and its answer gets appended to [`QA.md`](./QA.md) as a dated entry.
Because the working environment is ephemeral, entries are committed and pushed so
they survive across sessions.

## Entry format

```markdown
### Q<N>: <the question>
- **Date:** YYYY-MM-DD
- **A:** <the answer>
```

## Adding entries

Ask a question and request it be remembered. It will be appended to `QA.md`,
committed, and pushed.
